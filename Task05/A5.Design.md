
## A5.1 – Sentiment and Summary (2 Marks)

### 1. Sentiment Analysis

A lexicon-based sentiment scorer identifies
positive and negative words in citizen complaints.

Positive words:
good, clean, fast, helpful, improved

Negative words:
bad, dirty, slow, smoke, broken

Scoring Rules:
1. Positive word = +1
2. Negative word = -1
3. Neutral word = 0
4. A preceding negator such as "not" flips
   the sentiment score of the next sentiment word.

Example:
"The road is clean." = +1 (Positive)
"The air is bad." = -1 (Negative)
"The service is not good." = -1 (Negative)

Final Classification:
Score > 0 = Positive
Score < 0 = Negative
Score = 0 = Neutral

### 2. Extractive Summarisation

The summariser selects important sentences
from citizen complaints.

Steps:
1. Split complaints into sentences.
2. Convert text to lowercase.
3. Remove common stop words.
4. Count important word frequencies.
5. Score sentences using word frequencies.
6. Select the highest-scoring sentences.
7. Arrange selected sentences in original order.

Example:
"The road is dusty. Smoke is increasing.
The air quality is poor."

Summary:
"Smoke is increasing. The air quality is poor."

### Limitations

1. Sarcasm may be classified incorrectly.
2. Unrecognised words are ignored.
3. The summariser may miss context.
4. Simple negation rules cannot handle
   complex sentences.

### Conclusion

Lexicon-based sentiment analysis and extractive
summarisation provide a simple way to analyse
citizen complaints.

## A5.2 – Basic Chatbot (2 Marks)

### Rule-Based Chatbot

A rule-based chatbot answers citizens' questions
about air quality using keyword matching and
SQLite database queries.

### Working Process

1. Receive the user's question.
2. Convert the question to lowercase.
3. Identify keywords such as PM2.5,
   air quality, station, date and average.
4. Extract the station name and date.
5. Execute a parameterised SQLite query.
6. Display the result to the user.
7. Show a default message for unknown questions.

### Example

User: What is the PM2.5 in Adyar today?

Chatbot:
The chatbot searches the SQLite database
for Adyar's latest PM2.5 reading today
and displays the value in µg/m³.

### Sample SQL Query

SELECT pm25
FROM readings
WHERE station_id = ? AND date = ?
ORDER BY hour DESC
LIMIT 1;

### Limitations

1. It understands only predefined keywords.
2. It cannot handle complex questions.
3. Spelling mistakes may affect matching.
4. It cannot answer questions outside its rules.
5. Its answers depend on available database data.

### Alternative Concept and Complexity Analysis

A trained Naive Bayes model could classify
complaints using learned word probabilities.

The rule-based method is simple and requires
little memory, but has limited accuracy.

A trained model requires training data and
additional memory to store its parameters.

Prediction time depends on the number of
features and the model used.

A trained model may improve classification
accuracy, but this must be verified through
testing on labelled complaints.

### Conclusion

A rule-based chatbot is suitable for basic
air-quality questions, while a trained model
may be better for complex language.
